Get it

Download a released toolchain for 64-bit Linux, check its checksum, and point zig at it. Nothing else on your system changes.

Install the promoted toolchain

Before you start: the toolchain is not a static program. It needs the shared LLVM and Clang 21.1 libraries (libclang-cpp.so.21.1 and libLLVM.so.21.1). Without them, zig stops at start-up with “error while loading shared libraries”. On Debian testing, sudo apt install libclang-cpp21 brings both; on another system, install the packages that provide those two files.

The archive is 126 MB. Its SHA-256 is de6fb2ae924536f1a7b2eb085f5a3fa2e74c48fe4cbc2ba28b397647729faa36.

curl -LO https://repo.sparkyos.org/builds/cgm-zig/0.16.0%2Bcgm.046d6833/cgm-zig-x86_64-linux-0.16.0+cgm.046d6833.tar.xz
echo "de6fb2ae924536f1a7b2eb085f5a3fa2e74c48fe4cbc2ba28b397647729faa36  cgm-zig-x86_64-linux-0.16.0+cgm.046d6833.tar.xz" | sha256sum -c
tar xf cgm-zig-x86_64-linux-0.16.0+cgm.046d6833.tar.xz
ln -sfn "$PWD/cgm-zig-x86_64-linux-0.16.0+cgm.046d6833/bin/zig" ~/.local/bin/zig
zig version

The last command prints 0.16.0. To go back, use the upstream 0.16.0 tarball from ziglang.org, whose SHA-256 is 43186959edc87d5c7a1be7b7d2a25efffd22ce5807c7af99067f86f99641bfdf.

Try the newer candidate

It needs x86-64 Linux with compatible system LLVM and Clang 21.1 libraries. It is not a static, generally portable package: its library path is /usr/lib/llvm-21/lib and LLVM, Clang, zlib, zstd and the C and C++ runtimes are not bundled.

Verify the archive against the attached SHA256SUMS, extract it, keep bin/zig beside lib/zig, and run ./bin/zig directly. Do not replace your default compiler to evaluate it. On Debian-style multiarch systems, compiling against system headers may need an external ZIG_LIBC file, described in the build guide. The release page also lists a 605 MB evidence archive; never install the control binaries inside it.

Build it yourself

The fork’s working compiler is built in ReleaseSafe, with safety checks on, so a failure names itself. The recipe that worked:

cmake -B build-safe \
    -DCMAKE_BUILD_TYPE=RelWithDebInfo \
    -DZIG_RELEASE_SAFE=ON \
    -DZIG_STATIC_LLVM=OFF \
    -DZIG_EXTRA_BUILD_ARGS=-Ddebug-extensions
ninja -C build-safe

The result is build-safe/stage3/bin/zig. Use a fresh build-* folder inside the repository for each build. The two build-mode switches are not interchangeable: CMAKE_BUILD_TYPE=ReleaseSafe alone makes a stripped ReleaseFast compiler, so use the pair above. The build guide lists every obstacle met, with its control. A clean build under an 8-CPU mask on a busy host took about 41 minutes; the 8 to 9 minute figure is for an idle, unconstrained host.

Upstream’s own build instructions are preserved in README.upstream.md.
